## 本地扩展

本项目直接复用 [fy-hb/keep](https://github.com/fy-hb/keep) 的截图模板、字体、图标和地图。原版素材与 MIT 声明均随项目保留。

在项目目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，浏览器打开 `http://127.0.0.1:8765/`。

- 用「自定义背景」上传地图或照片，再用「底图缩放」或「移动底图」取景。导入路线后可用「适配路线」把轨迹放进截图的地图区域。
- 「可编辑轨迹」支持手绘、GPX 和 [路线 Skill](skills/trace-run-route/SKILL.md) 输出的 JSON。「随机配色」可重新生成分段颜色，导出沿用预览配色。
- GPX 会累计各段内的 GPS 距离，并在时间戳完整时填入用时。描线 JSON 按图片坐标叠加，使用原图才能对齐。GPX 的路线形状独立绘制，普通图片可作为背景。
- 配速支持 `05:30` 或原版的 `5.30`。填写用时后，按公里数重新计算配速。

#### 相比于原项目的改动

1.  增加了自定义头像和背景的功能.
2.  增加了更改截图中标题的功能(keep•户外运动).
3.  增加了更换天气的功能(目前支持: 晴, 多云, 阴).
4.  增加了绘制跑步路径的功能, 可选择路径是否随机发生变色, 并设置路径发生变色的概率.
5.  打开网页时, 自动填充当前时间, 并随机生成公里数与配速.
6.  高清重制了截图的界面部分.
7.  微调了截图中部分文字的组织形式及排布, 以及部分文字的字体
8.  调整了网页的部分界面.
9.  使用原生javascript重构了整体代码.
10.  替换了部分素材.

#### 使用说明

1.  修改"数据设置"部分的输入框中的内容即可更改截图中出现的各项数值.
2.  点击"保存图片"即可自动生成截图并下载到本地.
3.  自定义背景功能会将选择的图片置于界面的下方, 尽量保证选择的图片中有且只有地图, 没有其他多余的界面.
